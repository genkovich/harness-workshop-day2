# 01 · Перша відповідь через Flue

## Навіщо

Учора ми писали цикл самі. Сьогодні передаємо його Flue, а в коді задаємо модель та інструкцію. Спочатку перевіримо це без Telegram.

Початок: `start`. Готовий результат: `step-01-model`.

## Як працює

Відкрий `src/agent.ts`. Директива `'use agent'` позначає модуль агента. `useModel` обирає модель; рядок, який повертає `Assistant`, задає інструкцію. Це не повідомлення користувача.

`process.env.MODEL` читає налаштування з `.env`. Формат Flue: `provider/model-id`. `agentName` — стабільне імʼя, під яким runtime реєструє агента. Функція не містить власного while: цикл виконує Flue.

## Невеликі зміни

### `src/agent.ts`

1. Додай наступну частину в цей самий файл, зберігаючи порядок.

```ts
'use agent';
```

2. Додай наступну частину в цей самий файл, зберігаючи порядок.

```ts
import { useModel } from '@flue/runtime';
```

3. Додай наступну частину в цей самий файл, зберігаючи порядок.

```ts
export function Assistant() {
  // Провайдера та модель задаємо в .env; цикл виконує Flue.
  useModel(process.env.MODEL || 'google/gemini-2.5-flash');
```

4. Додай наступну частину в цей самий файл, зберігаючи порядок.

```ts
  // Це інструкція агента. Завдання передамо окремим повідомленням.
  return 'Reply in Ukrainian. Say when you do not know the answer.';
}
```

5. Додай наступну частину в цей самий файл, зберігаючи порядок.

```ts

```

## Перевірка

```bash
npm run typecheck
npm test -- --test-name-pattern "^(00|01) "
npm run ask -- "Привіт. Відповідай одним реченням."
```

У терміналі є відповідь моделі українською. Помилка ключа або моделі означає, що живу перевірку ще не пройдено.

Якщо тест падає, дивись назву перевірки й фактичний результат. Перевірка типів виявляє помилки TypeScript; локальні тести не доводять доступність провайдера. Для помилки API перевір ключ, точну назву моделі та відповідь сервісу в терміналі.

## Готовий код етапу

Це повний стан змінених файлів. Інші файли залишаються з попереднього етапу.

### `src/agent.ts`

```ts
'use agent';

import { useModel } from '@flue/runtime';

export function Assistant() {
  // Провайдера та модель задаємо в .env; цикл виконує Flue.
  useModel(process.env.MODEL || 'google/gemini-2.5-flash');

  // Це інструкція агента. Завдання передамо окремим повідомленням.
  return 'Reply in Ukrainian. Say when you do not know the answer.';
}

Assistant.agentName = 'workshop-assistant';
```
